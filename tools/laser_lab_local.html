Desktop Design Studio

Build your laser paths on the computer. Export files for the ESP32 project.

This page runs locally in your browser with no server. Draw vector paths, tune travel speed and dwell, and export either JSON or a ready-to-include C header for the ESP32 codebase.

The export is design data, not live projector control. Your current DMX fixture still cannot draw arbitrary shapes unless you later add ILDA or direct galvo output hardware.
