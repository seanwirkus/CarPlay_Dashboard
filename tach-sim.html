Notes

• Set Target RPM, watch RAW follow it tick-by-tick. If RAW jumps around with no noise, math/PPR is off.
• Crank Pulse jitter — RAW gets noisy, FILTERED should smooth. If FILTERED lags badly, EMA alpha too small or slew too tight.
• Crank Spurious edges — they hit ISR. MIN_PERIOD_US + SHORT_PERIOD_PCT should reject most. Watch rejection counters climb.
• Crank Missed pulse — period doubles randomly = RAW halves. If filter latches to half, SHORT_PERIOD_PCT is rejecting the recovery edge.
• Step mode shows slew limiter behavior. Sweep shows steady-state tracking error.
• Edit constants above live. Match firmware values in firmware/c3-sensor/main.cpp:100.
